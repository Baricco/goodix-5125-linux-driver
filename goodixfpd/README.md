# goodixfpd

Service for the Goodix `27c6:5125` / `27c6:5135` reader that implements
fprintd's D-Bus interface (`net.reactivated.Fprint`). It takes the place of
fprintd's daemon through a drop-in for `fprintd.service`; if the reader is not
present it starts the real fprintd. Installation and usage:
[`docs/INSTALL.md`](../docs/INSTALL.md).

## Layout

| | |
|---|---|
| `src/core/` | sensor protocol (USB CDC, commands, PSK, TLS-PSK on OpenSSL, finger detect, capture), image pipeline, SIFT and SIGFM matching in C |
| `src/daemon/gxd-device.c` | the `Device` object: sessions, Claim/Release, verify, identify, enroll, polkit, as in fprintd 1.94 |
| `src/daemon/gxd-manager.c` | `Manager` and ObjectManager |
| `src/daemon/gxd-sensor.c` | the sensor in a worker thread, events delivered to the main context |
| `src/daemon/gxd-template.c`, `gxd-storage.c` | fingerprints: matching, learning with use, on-disk format |
| `src/daemon/gxd-sensor-test.c` | simulated sensor (only in `goodixfpd-test`, never installed) |
| `src/daemon/*.xml` | interface description, from fprintd |
| `tests/` | `tls`, `template`, `dbus` |

## Building and testing

```sh
meson setup build                      # -Ddataset=<captures> for the matcher test
meson test -C build
meson setup build-asan -Db_sanitize=address,undefined && meson test -C build-asan
```

The `dbus` test starts a private system bus, a fake polkit and
`goodixfpd-test`, then uses the service the way pam_fprintd and the
`fprintd-*` commands do (including the real `pam_fprintd.so`, through
`pam_start_confdir`). The "fingers" are synthetic images generated by the
test; it needs `dbus-daemon`, `python-gobject` and `python-numpy`.

## Environment variables

Set them with a drop-in for `fprintd.service` (`Environment=`):

| | |
|---|---|
| `GOODIX_LEARN=0` | the fingerprint does not grow with use |
| `GOODIX_MIN_RIDGE` | minimum ridge contrast (default 10; 0 = no check) |
| `GOODIX_ENROLL_MIN_DIFF` | minimum difference between two enrollment touches (default 8) |
| `GOODIX_IMGPROC_*` | image pipeline parameters (see `src/core/goodix_imgproc.h`); changing them requires enrolling again |
| `GOODIX_DUMP_IMGPROC=1` | saves the raw frames in `/var/lib/fprint/goodix/` (calibration only) |
| `G_MESSAGES_DEBUG=goodixfpd` | detailed log |
